I’m a software developer who builds web applications from the data model up. I started Informatics Engineering at UPN in 2018 and have been shipping code on GitHub ever since.

Most of my work lives where Python, databases and the web meet. I’ve built a showroom catalog that keeps a car dealer’s whole inventory in order, a survey engine that rewrites its follow-up questions as people answer, and an AI assistant that works inside an existing business system: reading the data, flagging trends and taking routine decisions off people’s plates. Before that came Java Android apps, C++ tools, R Shiny dashboards and MATLAB classifiers; lately it’s Astro and Vite front ends.

I care about software that quietly makes someone’s day simpler: clean data, fast pages, fewer manual steps. If you’re building something and need a developer who thinks in systems, reach out on LinkedIn or browse my work on GitHub.
